# 보리보리쌀

객체지향프로그래밍 게임 프로젝트 (26031028 정민후)

움직이는 타이밍 바를 스페이스바로 멈춰 AI의 손을 피하는 순발력 QTE 게임입니다.

## 실행

`BoriBoriSsal/BoriBoriSsal.sln`을 Visual Studio에서 열거나 아래 명령을 실행합니다.

```powershell
dotnet run --project BoriBoriSsal/BoriBoriSsal.csproj
```

## 조작

- `Space`: 게임 시작 / 타이밍 바 정지 / 다시 시작
- `Esc`: 종료
- `Alt + Enter`: 전체화면 전환
